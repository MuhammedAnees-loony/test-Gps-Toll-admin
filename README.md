# 🛠️ GPS Toll System – Admin Panel

This repository contains the **Admin Panel** for the GPS Toll-Based System.

It is designed to provide administrators with a simple interface to **manage, monitor, and view information related to the main GPS Toll System**.

The admin panel works as the management interface for the main application and is intended for administrative use.

## ✨ Features

* 🔐 Admin login
* 📊 Admin dashboard
* 🚗 View and manage vehicle-related information
* 🛣️ Manage toll-related information
* 📍 Monitor system data
* 📋 View records and details
* ⚙️ Administrative controls

## 🔗 Main Project

This admin panel is a supporting component of the main **GPS Toll-Based System**.

**Main Project:**
https://github.com/MuhammedAnees-loony/Gps-Toll-System-V1

## 🛠️ Technologies Used

* HTML
* CSS
* JavaScript
* Web-based Admin Dashboard

## 📂 Purpose

The main GPS Toll System is responsible for the core toll calculation and GPS-based functionality, while this project provides the **administrative interface** for managing and monitoring the system.

```text
GPS Toll System
      │
      ├── Main Application
      │      └── GPS & Toll Processing
      │
      └── Admin Panel
             └── Management & Monitoring
```

## 🚀 Getting Started

### Clone the Repository

```bash
git clone https://github.com/MuhammedAnees-loony/test-Gps-Toll-admin.git
```

### Navigate to the Project

```bash
cd test-Gps-Toll-admin
```

Open the main HTML file in a browser or run it through your configured web server.
